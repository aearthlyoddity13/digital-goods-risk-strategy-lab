# Project overview — Digital Goods Merchant Risk Strategy Lab

**Owner:** Charlene Yang  
**Status:** Active repositioning (Phase 2)  
**Audience:** Recruiters and hiring managers in payments, credit/risk strategy, fintech product, financial infrastructure, emerging payments, and portfolio risk  
**Data boundary:** Aggregated and synthetic demonstration data only

## Executive summary

| Element | Statement |
|---------|-----------|
| **Problem** | Emerging digital-goods merchants (short drama, web fiction, games, AI services, virtual goods) challenge payment-platform underwriting because fulfillment is intangible, consumption can be immediate, frequency can be high, and traditional shipping evidence is limited. |
| **Strategic question** | How should a payment platform evaluate and control such merchants without over-blocking legitimate growth or under-controlling contingent exposure? |
| **Approach** | Research-led strategy demonstrator: industry analysis, risk taxonomy, content-risk framing, synthetic merchant scenarios, and an explainable rules-and-score decision engine. |
| **Deliverable** | Documented research artifact + interactive scenario lab + versioned API embeddable in a personal portfolio. |
| **Key insight** | Digital-goods risk is an interaction problem—ticket size, frequency, prepaid obligations, growth, and content/platform integrity jointly determine exposure—not a single rate threshold. |
| **Limitations** | Educational prototype. Not a production underwriting model. Thresholds are illustrative. No confidential processor or merchant data. Results must not be used for real merchant decisions. |

## Central research question

How should a payment platform evaluate and control emerging digital-goods merchants when products are intangible, consumption can be immediate, transaction frequency can be high, and traditional underwriting and fulfillment evidence are limited?

## What this project is

- A **research and strategy laboratory** for digital-goods merchant risk  
- An **explainable demonstration** of approve / control / review / decline logic  
- A **portfolio-ready** API and interactive module  

## What this project is not

- Not production underwriting software  
- Not a statistically validated predictive model  
- Not built on PayPal, processor, platform, or merchant-confidential data  
- Not an automated content-moderation system
